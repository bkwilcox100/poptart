## A calmer recording overlay

The overlay now slides in from the edge of the screen and slides back
out when you're done, instead of popping into place. It's smaller and
quieter too: the close button and recording dot are gone (releasing
your shortcut or pressing Escape covers both), and during silence the
waveform's resting line breathes gently so you know the mic is still
live.

## Everything from Handy 0.9.2–0.9.4

This release folds in upstream Handy through v0.9.4, including more
reliable pasting, automatic microphone recovery, a theme setting, a
secure-input warning with keyboard diagnostics, and four new languages
(Danish, Hindi, Nepali, Dutch) — all with Poptart's features intact.

## Safer AI cleanup

Dictated text is now fenced off from the cleanup model as data, so
speech that *sounds* like an instruction ("what time is it?") gets
cleaned up instead of answered.

## Auto-updates now work

Builds are signed with Poptart's own update key, so future releases
install right from the app.
